# Sales & Revenue Analysis Dashboard

This project is an interactive Power BI dashboard developed as Task 1 of my internship work at Thiranex.

The dashboard provides insights into:
- Total Revenue
- Total Profit
- Profit Margin
- Average Discount
- Product Performance
- Monthly Sales Trends

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization

## Features
- Dynamic KPI selection
- Interactive slicers and filters
- Trend analysis
- Product performance comparison
- Business insight visualization
